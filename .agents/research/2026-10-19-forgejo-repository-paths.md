# Forgejo repository paths and file conventions

Researched on 2026-10-19 against the Forgejo v17.0 documentation currently published as `latest`.

## Findings

| Template path                                            | Recognition / convention                                                                                                                                                                                                                                                                                                         | Content note                                                                                                                                                                                                                                                                           |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `template/.forgejo/FUNDING.yaml`                         | **Correct, documented.** Forgejo searches `.forgejo` first for a case-insensitive `FUNDING.yml`/`FUNDING.yaml` file, so this name and location are recognized.                                                                                                                                                                   | The `github`, `ko_fi`, and `thanks_dev` providers and values in the file match documented forms. This confirms convention only; instance configuration can add providers. [FUNDING files](https://forgejo.org/docs/latest/user/repository/funding/)                                    |
| `template/.forgejo/ISSUE_TEMPLATE/bug_report.yml`        | **Correct, documented.** `.forgejo` is a searched template directory; `ISSUE_TEMPLATE` is a permitted issue-template subdirectory spelling; issue forms may use arbitrary names and `.yml` is an allowed extension.                                                                                                              | Form fields (`name`, `about`, `title`, `labels`, `body`) follow the documented YAML-form example. [Issue and Pull Request Templates](https://forgejo.org/docs/latest/user/repository/issue-pull-request-templates/)                                                                    |

## Recognition is not validation

The issue-template and funding documents state the accepted paths and naming conventions. The Actions overview specifies `.forgejo/workflows` and `.yaml`; Forgejo's own repository lists `.yml` workflow files there and shows workflow runs, which confirms `.yml` use in practice.
This review covers path recognition, not workflow contents or runtime behavior. [Official Forgejo workflow directory](https://codeberg.org/forgejo/forgejo/src/branch/forgejo/.forgejo/workflows).
